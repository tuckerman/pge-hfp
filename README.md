# pge-hfp
xbar plugin to watch PGE Hourly Flex Pricing

## Installation

Install xbar (or SwiftBar) and copy pge-hourly-pricing.15m.py into your plugins folder.

## Variables

| Variable    | Purpose
|-------------|                                           |
| VAR_RATE    | Rate plan, e.g. EV2A                      |
| VAR_CIRCUIT | Representative circuit id, e.g. 083611114 |
| VAR_PROGRAM | Program name, e.g. CalFUSE                |
